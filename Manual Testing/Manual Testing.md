#### 💻 **What is Software?**

**Software** is a collection of instructions, data, or programs that tell a computer how to work. It is the **non-physical** part of a computer system – the part you can’t touch but you can interact with.

---
##### 🔸 **Types of Software:**

1. **System Software**
    - Helps run the computer hardware and system.
    - Examples:
        - **Operating Systems** (Windows, macOS, Linux)
        - **Device Drivers**
        - **Utilities** (Disk cleanup, antivirus)
            
2. **Application Software**
    - Software that allows users to do specific tasks.
    - Examples:
        - **Web Browsers** (Chrome, Firefox)
        - **Messaging Apps** (WhatsApp, Gmail)
        - **Media Players** (VLC, Spotify)
        - **Office Tools** (MS Word, Excel)
            
3. **Programming Software**
    - Used by developers to write code.
    - Examples:
        - Code Editors (VS Code, Sublime)
        - Compilers (GCC, javac)
        - Debuggers
            

---

##### 🔸 **How is Software Created?**
- Developers **write code** in programming languages like Python, Java, or C++.
- The code is then compiled and tested to make sure it works as expected.
- After development, it goes through **testing** (that’s where QA testers come in) to find and fix bugs before releasing it to users.

---

##### 🔸 **Why is Software Important?**

Software powers everything from your **phone**, **computer**, **car systems**, **ATMs**, to even **space missions**. Without software, the hardware (like your phone or laptop) would just be a lifeless machine.


#### ✅ **What is Software Testing?**

**Software Testing** is the process of **checking a software application** to make sure it:

- Works as expected
- Is free of bugs or issues
- Is easy to use and reliable
- Meets the business and user requirements
- is a quality product which can be delivered to client 

In simple words:
> **"Testing is checking if the software does what it's supposed to do—and doesn’t do what it shouldn’t!"**

---

#### 🔍 **Why is Testing Important?**

Without testing:
- Users may face crashes, errors, or broken features
- Businesses may lose money, users, or reputation
- Developers might not realize what’s broken until it’s too late

Think about a banking app:
- Imagine it transfers money to the wrong account—just because of a small bug 😱 That’s why **QA (Quality Assurance)** and testing are so important.
    

---

#### 🧪 **Types of Software Testing (High-Level)**

1. **Manual Testing**
    - Testers test the application **manually**, step-by-step
    - No coding or automation involved
    - Great for UI/UX, exploratory, and early-stage testing
        
2. **Automation Testing**
    - Uses scripts and tools to test faster and repeatedly
    - Good for regression and repetitive tasks
        
---
#### 📋 **What Do Testers Actually Do?**

As a **manual tester**, you will:
- Read and understand the **requirements**
- Create **test cases** (step-by-step instructions for testing a feature)
- Execute those steps in the app and note what happens
- Report **bugs** if something doesn’t work right
- Work closely with developers to get those bugs fixed
    
---

#### 🧠 Example:

You’re testing a login page:
- Step 1: Open the app
- Step 2: Enter username and password
- Step 3: Click Login
- **Expected**: It should log you in
- **Actual**: The app crashes

➡ You found a **bug** and will report it.
