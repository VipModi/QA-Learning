## 🔁 **1. Verification vs Validation**

| Term      | Verification                       | Validation                         |
| --------- | ---------------------------------- | ---------------------------------- |
| **What?** | Are we building the product right? | Are we building the right product? |
| **Focus** | Process, design, documents         | Final product and behavior         |
| **How?**  | Reviews, walkthroughs, checklists  | Running the application, testing   |
| **When?** | Early in development               | After development                  |
| **Type**  | Static Testing                     | Dynamic Testing                    |

---

## ⚖️ **2. QA vs QC**

|Term|QA (Quality Assurance)|QC (Quality Control)|
|---|---|---|
|**Focus**|Process, Prevention|Product, Detection|
|**Goal**|Avoid defects|Find and fix defects|
|**How?**|Standards, process improvement|Test execution, bug reporting|
|**Type**|Involves **Verification**|Involves **Validation**|

---

## 🧘‍♂️ **3. Static Testing vs Dynamic Testing**

|Term|Static Testing|Dynamic Testing|
|---|---|---|
|**What is it?**|Testing without running the software|Testing by executing the software|
|**How it’s done**|Reviews, walkthroughs, code analysis|Manual/automated test execution|
|**When?**|Early stages (requirement, design)|After development|
|**Involves?**|**Verification**|**Validation**|

---

## 🔗 **How are they connected?**

Here’s a simple way to visualize it:

|Concept|Related To|Method|Focus|
|---|---|---|---|
|**Verification**|QA|Static Testing|Process|
|**Validation**|QC|Dynamic Testing|Product|

---

### 🧠 Summary:
- **Verification** ↔ **QA** ↔ **Static Testing**
- **Validation** ↔ **QC** ↔ **Dynamic Testing**
    

Each group supports the next:
- **QA** uses **verification** (reviews, process checks) to **prevent defects**.
- **QC** uses **validation** (test execution) to **detect and fix defects**.
