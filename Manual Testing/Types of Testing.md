
### 1. Based on Execution Method

#### 1.1 Manual Testing
- Exploratory Testing
- Ad-hoc Testing
- Usability Testing
- Acceptance Testing (UAT)
- UI Testing

#### 1.2 Automation Testing
- Smoke Testing
- Regression Testing
- Data-Driven Testing
- Keyword-Driven Testing
- Performance Testing (via tools)

---

### 2. Based on Knowledge of Code (Box Approach)

#### 2.1 Black Box Testing (no knowledge of code)
- Functional Testing
- System Testing
- Acceptance Testing
- UI Testing
- Regression Testing

#### 2.2 White Box Testing (full knowledge of code)
- Unit Testing
- Code Coverage Testing
- Branch/Condition Testing
- Loop Testing
- Path Testing

#### 2.3 Gray Box Testing (partial knowledge)
- Integration Testing
- Security Testing
- Database Testing

---

### 3. Based on Testing Levels

#### 3.1 Unit Testing
- Performed by developers
- Focuses on individual functions/modules
- Usability and UI testing 

#### 3.2 Integration Testing
- Checks interaction between modules
- Can be:
    - Top-down
    - Bottom-up
    - Big Bang
    - Incremental

#### 3.3 System Testing
- Tests the entire integrated application
- Both functional and non-functional

#### 3.4 Acceptance Testing
- Ensures the software meets business needs
- Includes:
    - Alpha Testing
    - Beta Testing
    - UAT (User Acceptance Testing)
        

---

### 4. Based on Test Strategy / Integration Approach

#### 4.1 Incremental Testing
- Modules integrated and tested step-by-step
- Easier to debug

#### 4.2 Non-Incremental Testing (Big Bang)
- All modules integrated at once and tested together
- Harder to isolate issues

---

### 5. Based on Purpose

#### 5.1 Functional Testing
- Smoke Testing
- Sanity Testing
- Regression Testing
- Re-Testing
- End-to-End Testing
- Exploratory Testing
- Ad-hoc Testing

#### 5.2 Non-Functional Testing
- Performance Testing (Load, Stress, Spike)
- Security Testing
- Usability Testing
- Compatibility Testing
- Accessibility Testing
- Reliability Testing

---

### 6. Based on Test Design Techniques

#### 6.1 Black Box Techniques
- Equivalence Partitioning
- Boundary Value Analysis
- Decision Table Testing
- State Transition Testing
- Error Guessing

#### 6.2 White Box Techniques
- Statement Coverage
- Branch Coverage
- Path Coverage
- Condition Coverage
